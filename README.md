# Yandex HA Bridge

Кастомная интеграция для Home Assistant, которая получает устройства Яндекса через официальный API и добавляет выбранные устройства непосредственно в Home Assistant.

## Текущая версия

**0.4.0 — пресеты, сцены и расширенное состояние света**

Интеграция работает через Config Flow: OAuth-токен → список устройств → выбор устройств → Config Entry.

Каждое выбранное физическое устройство Яндекса регистрируется в Home Assistant как отдельный **Device**.

## Что нового в 0.4.0

- Исправлен разбор `color_model: hsv`, когда Яндекс возвращает строку, а не список.
- HSV-лампы используют Home Assistant `HS`, без искусственного `RGB`.
- Исправлен разбор реального диапазона `temperature_k.min/max`.
- Добавлены атрибуты состояния: Online, Power, Brightness, Color, Temperature, Mode.
- Добавлена отдельная `select` entity **Режим** для цветных ламп.
- Добавлены быстрые пресеты: Тёплый свет, Нейтральный свет, Холодный свет, Красный, Зелёный, Синий.
- Добавлены сцены, которые устройство реально рекламирует через `color_scene`.
- Пресеты HSV сохраняют текущую яркость.
- Выбор пресета или сцены включает лампу.
- `available` отражает `state=online`, возвращаемый Яндекс API.

## Возможности

- OAuth-токен Яндекса.
- Права `iot:view` и `iot:control`.
- Получение устройств через официальный Yandex Smart Home API.
- Выбор устройств при установке и через Options Flow.
- Отдельный Device Registry для каждого выбранного устройства.
- Включение/выключение света.
- Яркость 0–100% с преобразованием в Home Assistant 0–255.
- HSV → Home Assistant HS.
- RGB только для устройств, которые явно рекламируют `rgb`.
- Цветовая температура.
- Быстрые цветовые и температурные пресеты.
- Яндекс-сцены через `color_scene`.
- Диагностические атрибуты.
- Периодическое обновление состояния.

## Состояние устройства

Light entity содержит диагностические атрибуты:

- `yandex_online`
- `yandex_power`
- `yandex_brightness`
- `yandex_color`
- `yandex_temperature`
- `yandex_mode`
- `yandex_device_id`
- `yandex_device_type`
- `yandex_state`
- `yandex_room`
- `yandex_group`
- `yandex_manufacturer`
- `yandex_model`
- `yandex_color_model`
- диапазоны яркости и цветовой температуры

Эти атрибуты предназначены в том числе для пользовательского Dashboard Home Assistant.

## Пресеты и сцены

Для цветных ламп создаётся дополнительная `select` entity **Режим**.

Быстрые пресеты:

- Тёплый свет — 2700 K.
- Нейтральный свет — 4000 K.
- Холодный свет — 6500 K.
- Красный — HSV H=0, S=100.
- Зелёный — HSV H=120, S=100.
- Синий — HSV H=240, S=100.

Дополнительно автоматически добавляются сцены из `color_scene`, которые сообщает конкретная лампа. Список зависит от реальных capabilities устройства.

Например, устройство может рекламировать: Чудо, Сказочные огни, Северное сияние, Рождество, Алиса, Вечеринка, Джунгли, Неон, Ночь, Океан, Романтика, Свеча, Сирена, Тревога, Фантазия и Чтение.

## Важное про физический выключатель

Интеграция использует cloud polling и по умолчанию обновляет состояние каждые 30 секунд.

Если физический выключатель обесточивает умную лампу, Home Assistant сможет показать `OFF` только если Яндекс API после этого возвращает соответствующее состояние. Если API продолжает возвращать `on=true`, интеграция не может достоверно определить обесточивание только через этот API.

`state=online` означает состояние подключения, а не состояние питания лампы. Поэтому Online и Power являются разными показателями.

## Важное про HTTP 403

`GET /v1.0/user/info` и `GET /v1.0/devices/{device_id}` используют `iot:view`, а `POST /v1.0/devices/actions` использует `iot:control`.

Токен должен иметь оба права: `iot:view` и `iot:control`.

## Установка

Репозиторий устанавливается через HACS как custom integration.

1. **Настройки → Устройства и службы**.
2. **Добавить интеграцию**.
3. Найдите **Yandex HA Bridge**.
4. Введите OAuth-токен с `iot:view` и `iot:control`.
5. Получите список устройств.
6. Выберите устройства.
7. Сохраните Config Entry.

Удалять существующий Device или Config Entry перед обновлением не требуется.

## Проверка после обновления

Для HSV-лампы с `color_model: hsv` ожидается:

- `light` entity внутри Device.
- Home Assistant `HS`, а не RGB.
- Рабочее включение/выключение.
- Яркость.
- Цветовая температура.
- `Режим` с быстрыми пресетами и сценами.
- Атрибуты состояния с Yandex ID и текущими значениями.

Если команда из стандартной Light Card не работает, проверьте **Настройки → Система → Журналы** и ищите `yandex_ha_bridge`.

## Dashboard

Интеграция отдаёт стандартные Home Assistant entities и диагностические атрибуты. Красивый планшетный Dashboard строится отдельно средствами Home Assistant и может использовать эти данные для отображения:

```text
Online
Питание       Включено
Яркость       50 %
Цвет          Красный
Температура   —
Режим         HSV
Yandex ID     350f0197-17a7-4785-...
```

## Архитектура

Основная работа выполняется custom integration `custom_components/yandex_ha_bridge`.

App `yandex_ha_bridge` используется для диагностики и технического обслуживания. Управление устройствами выполняется непосредственно интеграцией через официальный API.

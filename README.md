# Yandex HA Bridge

Кастомная интеграция для Home Assistant, которая получает устройства Яндекса через официальный API Яндекса и добавляет выбранные устройства непосредственно в Home Assistant.

## Текущая версия

**0.3.4 — исправление запуска custom integration**

Интеграция работает через Config Flow: OAuth-токен → получение списка устройств → выбор устройств → создание Config Entry в Home Assistant.

Используется уникальный домен `yandex_ha_bridge`, поэтому интеграция может работать одновременно со сторонней интеграцией `yandex_smart_home`.

## Как это работает

```text
        Яндекс Умный дом
               │
               │ официальный API
               ▼
       Yandex HA Bridge
               │
               ▼
        Home Assistant
               │
               ▼
        light / устройства
```

Устройства не удаляются и не переносятся из Яндекса. Интеграция получает к ним доступ через API Яндекса.

## Установка через HACS

Добавьте репозиторий `menfis911/hassio-yandex-bridge` в HACS как пользовательский репозиторий категории **Integration**.

После установки перезапустите Home Assistant.

Затем откройте:

**Настройки → Устройства и службы → Добавить интеграцию → Yandex HA Bridge**

Не удаляйте существующую интеграцию **Yandex Smart Home**: Yandex HA Bridge использует отдельный домен `yandex_ha_bridge` и предназначена для совместной работы с ней.

## Настройка

1. Запустите добавление интеграции **Yandex HA Bridge**.
2. Введите OAuth-токен Яндекса.
3. Интеграция запросит список доступных устройств.
4. Для первого теста выберите **одно устройство**.
5. Нажмите сохранить.
6. После создания Config Entry Home Assistant получит состояние выбранного устройства и создаст поддерживаемую сущность.

Для получения списка устройств токен должен иметь право `iot:view`. Для управления устройствами требуется `iot:control`.

## Первый тест

После обновления до 0.3.4:

1. Перезапустите Home Assistant.
2. Не удаляйте существующую Config Entry.
3. Убедитесь, что выбран один тестовый девайс.
4. Проверьте появление устройства и сущности.
5. Проверьте чтение состояния.
6. Затем проверим `on/off`, яркость, цвет и цветовую температуру — только те функции, которые поддерживает конкретное устройство.
7. После этого проверим двусторонний сценарий **HA → Яндекс → HA**.

## Безопасность

OAuth-токен хранится в конфигурации Home Assistant.

Токен **никогда не должен добавляться в GitHub, README, CHANGELOG, Dockerfile или исходный код**.

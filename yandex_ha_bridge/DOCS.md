# Yandex HA Bridge — полная инструкция

## Что это

Проект состоит из двух частей:

1. **Yandex HA Bridge App** — отдельное приложение Home Assistant с веб-панелью для диагностики и работы с API Яндекса.
2. **Yandex Smart Home Integration** — стандартная интеграция Home Assistant, которая добавляется через **Настройки → Устройства и службы** и создаёт реальные устройства и сущности Home Assistant.

Устройства остаются подключёнными к Яндексу. Alice продолжает работать как раньше.

Архитектура:

```text
                 Home Assistant
                       │
          ┌────────────┴────────────┐
          │                         │
   Yandex HA Bridge App      Yandex Smart Home
   боковая панель             Integration
          │                         │
          └────────────┬────────────┘
                       │
                 Yandex API
                       │
                 Яндекс Умный дом
                       │
                   устройства
```

## Текущая версия

**0.3.0** — добавлена полноценная интеграция Home Assistant с Config Flow и выбором устройств через стандартный интерфейс HA.

Для устройств типа `light` поддерживаются:

- включение;
- выключение;
- яркость;
- RGB-цвет;
- цветовая температура, если её предоставляет устройство.

## Требования

- Home Assistant с поддержкой custom integrations.
- Доступ в интернет из Home Assistant.
- OAuth-токен Яндекса с правом `iot:view`.
- Для управления устройствами дополнительно требуется `iot:control`.

Официальный API Яндекса: `https://api.iot.yandex.net`.

## 1. Установка Yandex HA Bridge App

1. Откройте **Настройки → Приложения**.
2. Откройте меню **App repositories / Репозитории приложений**.
3. Добавьте репозиторий:

   `https://github.com/menfis911/hassio-yandex-bridge`

4. Найдите **Yandex HA Bridge**.
5. Установите приложение.
6. В конфигурации приложения можно указать OAuth-токен Яндекса и параметры логирования.
7. Запустите приложение.
8. При включённом Ingress в боковом меню появится **Yandex HA Bridge**.

Веб-панель приложения оставлена как дополнительный интерфейс диагностики и проверки списка устройств.

## 2. Установка интеграции Yandex Smart Home

Приложение и интеграция — разные компоненты Home Assistant. Установка App сама по себе не устанавливает custom integration.

Рекомендуемый способ установки интеграции — HACS.

### Через HACS

1. Откройте **HACS → Integrations**.
2. Откройте меню HACS и выберите **Custom repositories / Пользовательские репозитории**.
3. Добавьте:

   `https://github.com/menfis911/hassio-yandex-bridge`

4. В качестве типа выберите **Integration**.
5. Найдите **Yandex Smart Home**.
6. Установите интеграцию.
7. Перезапустите Home Assistant, если HACS попросит это сделать.

После установки интеграция появится в стандартном мастере добавления устройств Home Assistant.

## 3. Добавление интеграции

Откройте:

**Настройки → Устройства и службы → Добавить интеграцию**

Найдите:

**Yandex Smart Home**

### Шаг 1 — OAuth-токен

Введите OAuth-токен Яндекса.

Для чтения устройств необходим scope:

`iot:view`

Для управления устройствами:

`iot:control`

Токен не публикуется в GitHub и не должен попадать в исходный код.

### Шаг 2 — выбор устройств

Интеграция получает список устройств через официальный API Яндекса.

Отметьте только те устройства, которые должны появиться в Home Assistant.

Например:

```text
☑ Лампочка спальня
☑ Лампочка кухня
☐ Чайник
☐ Телевизор
```

После завершения мастера выбранные устройства создаются в Home Assistant.

Не выбранные устройства интеграция не создаёт.

## 4. Что появляется в Home Assistant

Для совместимых ламп создаётся стандартная сущность Home Assistant типа `light`.

Например:

```text
light.lampochka_spalnya
```

Устройство получает нормальную запись в **Device Registry**, а сущность — в **Entity Registry**.

Это позволяет использовать лампочки в:

- Dashboard;
- автоматизациях;
- сценариях;
- сценах;
- голосовом управлении Home Assistant;
- любых стандартных механизмах Home Assistant.

## 5. Управление лампочкой

Если Yandex API сообщает соответствующие capabilities, интеграция поддерживает:

### Включение и выключение

Используется capability `devices.capabilities.on_off`.

### Яркость

Используется capability `devices.capabilities.range` с instance `brightness`.

Home Assistant работает с яркостью 0–255, а API Яндекса — с процентами 0–100. Интеграция выполняет преобразование автоматически.

### RGB

Если лампа поддерживает `rgb` или `hsv`, Home Assistant показывает управление цветом.

Яндекс использует capability `devices.capabilities.color_setting`.

### Цветовая температура

Если устройство сообщает `temperature_k`, Home Assistant получает режим цветовой температуры.

Для каждой лампы используются реальные `min` и `max`, которые возвращает Яндекс API.

## 6. Изменение списка устройств

Откройте:

**Настройки → Устройства и службы → Yandex Smart Home → Настроить**

После этого можно изменить список выбранных устройств.

Интеграция повторно получает список устройств из Яндекса и показывает актуальный выбор.

## 7. Боковая панель Yandex HA Bridge

Пункт **Yandex HA Bridge** в боковом меню остаётся.

Он предназначен для:

- проверки соединения с Yandex API;
- просмотра найденных устройств;
- диагностики;
- просмотра логов;
- технического обслуживания App.

Основной способ добавления устройств в Home Assistant — стандартная интеграция через **Настройки → Устройства и службы**.

## 8. OAuth и безопасность

Токен хранится локально в Home Assistant.

Никогда не публикуйте его в GitHub, README, CHANGELOG, Dockerfile, исходном коде, логах или скриншотах.

Если токен был опубликован, его необходимо отозвать и создать новый.

## 9. Проверка API

Основные методы официального API:

```text
GET  /v1.0/user/info
GET  /v1.0/devices/{device_id}
POST /v1.0/devices/actions
```

Для чтения используется `iot:view`, для управления — `iot:control`.

## 10. Диагностика

Если интеграция не добавляется:

1. Проверьте OAuth-токен.
2. Убедитесь, что токен имеет `iot:view`.
3. Проверьте доступ Home Assistant к интернету.
4. Откройте **Настройки → Система → Журналы**.
5. Найдите сообщения `yandex`.

Если устройство найдено, но не управляется, проверьте наличие у токена права `iot:control` и capabilities конкретного устройства.

## 12. Важное ограничение текущего релиза

В версии 0.3.0 основной сценарий для пользователя уже перенесён в стандартную Home Assistant Integration.

Старая форма выбора устройств в App остаётся как технический/диагностический интерфейс, но **не является основным способом создания устройств Home Assistant**.

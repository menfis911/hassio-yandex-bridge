# Yandex HA Bridge — полная инструкция

## Что это

Проект состоит из двух частей:

1. **Yandex HA Bridge App** — отдельное приложение Home Assistant с веб-панелью для диагностики и работы с API Яндекса.
2. **Yandex HA Bridge Integration** — стандартная custom integration Home Assistant, которая добавляется через **Настройки → Устройства и службы → Добавить интеграцию** и создаёт реальные устройства и сущности Home Assistant.

Устройства остаются подключёнными к Яндексу. Alice продолжает работать как раньше.

Архитектура:

```text
                 Home Assistant
                       │
          ┌────────────┴────────────┐
          │                         │
   Yandex HA Bridge App      Yandex HA Bridge
   боковая панель             Integration
   диагностика                реальные устройства
          │                         │
          └────────────┬────────────┘
                       │
                 Yandex API
                       │
                 Яндекс Умный дом
                       │
                   устройства
```

## Текущая версия

**0.3.2** — синхронизирована версия App и custom integration, удалена устаревшая интеграция с доменом `yandex`, а основная интеграция использует уникальный домен `yandex_ha_bridge`.

Для устройств типа `light` поддерживаются:

- включение;
- выключение;
- яркость;
- RGB-цвет;
- цветовая температура, если её предоставляет устройство.

## Требования

- Home Assistant с поддержкой custom integrations.
- Доступ в интернет из Home Assistant.
- OAuth-токен Яндекса с правом `iot:view`.
- Для управления устройствами дополнительно требуется `iot:control`.

Официальный API Яндекса: `https://api.iot.yandex.net`.

## 1. Установка Yandex HA Bridge App

1. Откройте **Настройки → Приложения**.
2. Откройте меню **App repositories / Репозитории приложений**.
3. Добавьте репозиторий:

   `https://github.com/menfis911/hassio-yandex-bridge`

4. Найдите **Yandex HA Bridge**.
5. Установите App и запустите его.
6. В разделе конфигурации укажите OAuth-токен Яндекса.

App нужна для диагностики и технической проверки API. Реальные устройства Home Assistant добавляются через custom integration.

## 2. Установка Yandex HA Bridge Integration

Если интеграция устанавливается через HACS:

1. Откройте **HACS → Integrations**.
2. Добавьте репозиторий `menfis911/hassio-yandex-bridge` как пользовательский репозиторий типа **Integration**.
3. Установите **Yandex HA Bridge**.
4. Перезапустите Home Assistant.

После перезапуска откройте:

**Настройки → Устройства и службы → Добавить интеграцию → Yandex HA Bridge**

Важно: не удаляйте и не изменяйте стороннюю интеграцию **Yandex Smart Home**. Наша интеграция использует отдельный домен `yandex_ha_bridge` и должна работать рядом с ней.

## 3. Добавление устройств

1. В Home Assistant запустите добавление **Yandex HA Bridge**.
2. Введите OAuth-токен Яндекса.
3. Integration запросит список доступных устройств через API.
4. Выберите нужные устройства.
5. Нажмите **Сохранить**.
6. Выбранные устройства появятся в Home Assistant как устройства и сущности соответствующих поддерживаемых платформ.

Для получения списка устройств токен должен иметь право `iot:view`. Для управления устройствами требуется `iot:control`.

## 4. Изменение списка устройств

Откройте карточку интеграции **Yandex HA Bridge** и используйте **Настроить / Configure**. Options Flow повторно получает список устройств Яндекса и позволяет изменить выбранные устройства.

## 5. Веб-панель App

Боковая панель **Yandex HA Bridge** относится к App и предназначена для диагностики API и технического обслуживания.

Она не заменяет custom integration и не должна использоваться как основной способ создания сущностей Home Assistant.

## 6. Совместимость со сторонней Yandex Smart Home

Наша интеграция использует:

```text
domain = yandex_ha_bridge
name   = Yandex HA Bridge
```

Она не использует домен `yandex_smart_home` и не должна конфликтовать со сторонней интеграцией **Yandex Smart Home**.

Если в системе уже установлена сторонняя Yandex Smart Home, оставьте её без изменений.

## 7. Если интеграция не появляется в списке

Проверьте по порядку:

1. В HACS установлена именно **Yandex HA Bridge**.
2. После установки выполнен полный перезапуск Home Assistant.
3. В каталоге `/config/custom_components/yandex_ha_bridge/` присутствуют файлы `manifest.json`, `config_flow.py`, `__init__.py`, `strings.json`.
4. В `manifest.json` указан домен `yandex_ha_bridge`.
5. В логах Home Assistant нет ошибки загрузки `custom_components.yandex_ha_bridge`.
6. Удалите старую копию нашей интеграции из HACS, если она была установлена до переименования, затем установите актуальную версию заново.

Не создавайте папку `custom_components/yandex`: это старый вариант интеграции и он больше не используется проектом.

## Безопасность

OAuth-токен хранится в конфигурации Home Assistant.

Токен **никогда не должен добавляться в GitHub, README, CHANGELOG, Dockerfile или исходный код**.

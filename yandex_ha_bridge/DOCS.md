# Yandex HA Bridge — документация

## Назначение

Аддон подключается к официальному API Яндекс Умного дома и предоставляет Home Assistant доступ к информации об устройствах пользователя.

Устройства при этом остаются подключёнными к Яндексу. Alice продолжает работать без изменений.

## Текущая версия: 0.1.1

Версия **0.1.1** работает в режиме только чтения.

Аддон:

1. подключается к API Яндекса;
2. проверяет OAuth-токен;
3. получает список устройств;
4. автоматически ищет устройство модели `YNDX-00019`;
5. получает его текущее состояние;
6. выводит диагностическую информацию в лог.

Управление устройством пока отключено.

## OAuth-токен

Для чтения устройств нужен OAuth-токен с разрешением `iot:view`.

Официальный API Яндекса использует адрес:

`https://api.iot.yandex.net`

Для получения списка устройств используется:

`GET /v1.0/user/info`

Для получения состояния конкретного устройства используется:

`GET /v1.0/devices/{device_id}`

Токен передаётся в HTTP-заголовке:

`Authorization: Bearer YOUR_OAUTH_TOKEN`

Для тестирования Яндекс также предоставляет отладочный OAuth-токен.

## Настройка аддона

Откройте **Настройки → Дополнения → Yandex HA Bridge → Конфигурация**.

### `yandex_oauth_token`

OAuth-токен Яндекса.

Токен хранится в локальной конфигурации Home Assistant и не должен публиковаться в GitHub.

### `device_id`

Идентификатор конкретного устройства Яндекса.

Поле необязательное.

Если оставить его пустым, аддон автоматически ищет устройство с моделью `YNDX-00019`.

Если указать `device_id`, поиск выполняется только по этому идентификатору.

### `poll_interval`

Интервал между запросами к API в секундах.

По умолчанию: `30` секунд.

Минимальное значение: `10` секунд.

### `log_level`

Уровень логирования:

- `debug` — подробная диагностика;
- `info` — обычный режим;
- `warning` — только предупреждения и ошибки;
- `error` — только ошибки.

## Проверка работы

После запуска в журнале должны появиться сообщения примерно такого вида:

```text
Yandex HA Bridge v0.1.1 запускается
Соединение с API Яндекс Умного дома установлено
Найдено устройство: id=..., имя=..., модель=YNDX-00019
Тип устройства: devices.types.light
Умения: [...]
Текущее состояние устройства успешно получено
```

Если токен неверный или не имеет `iot:view`, появится сообщение об ошибке авторизации.

Если устройство не найдено, будет выведено предупреждение.

## Безопасность

Никогда не публикуйте OAuth-токен:

- в GitHub;
- в README;
- в CHANGELOG;
- в Dockerfile;
- в исходном коде;
- в скриншотах логов.

## Версионность

Полная история релизов хранится в `CHANGELOG.md`.

Home Assistant определяет наличие обновления по версии из `config.yaml`.

Правила проекта:

- `0.1.x` — чтение и диагностика;
- `0.2.x` — управление устройствами;
- `0.3.x` — сущности Home Assistant;
- `0.4.x` — синхронизация состояния;
- `0.5.x+` — расширение поддержки устройств.

## План развития

### 0.2.0

Добавить управление светом через `POST /v1.0/devices/actions` с правом `iot:control`.

### 0.3.0

Добавить автоматическое создание сущности `light` в Home Assistant через MQTT Discovery.

### 0.4.0

Добавить двустороннюю синхронизацию состояния и обновление состояния после команд.

### Далее

Добавить поддержку нескольких устройств, дополнительных типов устройств и автоматического восстановления после временной потери соединения.

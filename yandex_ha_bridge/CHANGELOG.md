# История изменений

## 0.3.4 — 8 сентября 2026

### Исправление запуска custom integration
- Исправлена ошибка запуска интеграции в актуальном Home Assistant: `DataUpdateCoordinator` больше не использует недоступный `hass.logger`.
- Для `DataUpdateCoordinator` используется стандартный module logger Python (`logging.getLogger(__name__)`).
- Синхронизированы версии App, custom integration и исходного кода: **0.3.4**.
- Обновлена проверка версии в GitHub Actions.
- После успешной validation, сборки `amd64` и `aarch64` и публикации multi-arch manifest автоматически создаются tag `v0.3.4` и GitHub Release.
- Полная инструкция приведена в соответствие с фактической структурой проекта: актуальная integration использует `translations/en.json` и `translations/ru.json`; `strings.json` не используется.

## 0.3.3 — 8 сентября 2026

### Home Assistant Integration
- Исправлена структура переводов custom integration: добавлены `translations/en.json` и `translations/ru.json`.
- Удалён устаревший `strings.json`.
- Синхронизирована версия интеграции и App: **0.3.3**.
- Исправлена загрузка Config Flow в актуальном Home Assistant.

## 0.3.2 — 8 сентября 2026

### Синхронизация и исправления
- Синхронизирована версия App, custom integration и исходного кода: **0.3.2**.
- Исправлены оставшиеся ссылки на версию **0.3.0** в App.
- Исправлены тексты веб-панели: основной способ добавления устройств теперь корректно называется **Yandex HA Bridge Integration**.
- Удалена устаревшая custom integration из `custom_components/yandex`, которая использовала домен `yandex` и могла путать Home Assistant с новой интеграцией.
- Оставлена только актуальная custom integration `custom_components/yandex_ha_bridge` с доменом `yandex_ha_bridge`.
- Обновлена полная инструкция.

## 0.3.1 — 8 сентября 2026

### Home Assistant Integration
- Интеграция переименована в **Yandex HA Bridge**.
- Используется уникальный домен `yandex_ha_bridge`.
- Убрана конфликтующая идентичность `yandex_smart_home`.
- Интеграция может работать одновременно со сторонней **Yandex Smart Home**.
- Config Flow: OAuth-токен → получение устройств → выбор устройств → создание Config Entry.
- Options Flow позволяет изменить список выбранных устройств.
- Выбранные устройства регистрируются через Device Registry Home Assistant.

### Свет
- Добавлена сущность `light` для совместимых устройств.
- Включение и выключение.
- Яркость.
- RGB/HSV.
- Цветовая температура.
- Преобразование яркости между шкалами Home Assistant 0–255 и Яндекс 0–100.

### HACS и документация
- Обновлено имя интеграции в `hacs.json`.
- Обновлены README и описания.
- Версия аддона и build pipeline синхронизированы с 0.3.1.

## 0.3.0 — 8 сентября 2026

### Home Assistant Integration
- Добавлена отдельная стандартная custom integration.
- Добавлен Config Flow: токен → получение устройств → выбор устройств.
- Выбранные устройства сохраняются в Config Entry Home Assistant.
- Добавлен Options Flow для изменения списка выбранных устройств.

### Свет
- Добавлена сущность `light` для совместимых устройств.
- Поддержаны включение и выключение через `devices.capabilities.on_off`.
- Поддержана яркость через `devices.capabilities.range` / `brightness`.
- Поддержан RGB/HSV через `devices.capabilities.color_setting`.
- Поддержана цветовая температура через `temperature_k`.

### Архитектура
- Основной способ добавления устройств перенесён в **Настройки → Устройства и службы**.
- Боковая панель Yandex HA Bridge сохранена для диагностики и технического обслуживания App.
- Добавлены HACS-метаданные для установки custom integration.

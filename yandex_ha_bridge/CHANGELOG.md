# История изменений

В этом файле хранится полная история всех версий аддона.

## 0.1.1 — 8 сентября 2026

### Исправления
- Исправлена авторизация запросов к официальному API Яндекс Умного дома: используется стандартный `Bearer` OAuth-заголовок.
- Улучшена обработка ошибок авторизации и сетевых ошибок.
- Добавлены более понятные сообщения в логах аддона.

### Интерфейс и документация
- Описание аддона переведено на русский язык.
- Документация и настройки дополнены русскими пояснениями.
- Добавлена русская локализация полей конфигурации.

### Функциональность
- Сохранён режим только чтения.
- Автоматически ищется устройство модели `YNDX-00019`, если `device_id` не указан вручную.
- Получается текущее состояние найденного устройства.
- Управление устройством в этой версии намеренно не выполняется.

## 0.1.0 — 8 сентября 2026

### Первый релиз
- Создан аддон-мост между Яндекс Умным домом и Home Assistant.
- Добавлена настройка OAuth-токена Яндекса.
- Добавлено чтение устройств через официальный API Яндекс Умного дома.
- Добавлен поиск устройства `YNDX-00019`.
- Добавлено периодическое получение состояния устройства.
- Поддерживаются архитектуры `amd64` и `aarch64`.
- Управление устройствами в этой версии отключено.

## План развития

- **0.2.0** — управление устройством: включение, выключение, яркость, RGB и цветовая температура.
- **0.3.0** — создание сущности `light` в Home Assistant через MQTT Discovery.
- **0.4.0** — полноценная синхронизация состояния между Яндексом и Home Assistant.
- **0.5.0+** — несколько устройств, дополнительные типы устройств и расширенные возможности.

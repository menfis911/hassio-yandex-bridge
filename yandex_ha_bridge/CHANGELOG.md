# История изменений

В этом файле хранится полная история всех версий аддона.

## 0.2.1 — 8 сентября 2026

### Исправления
- Обновлена версия релиза для принудительного обновления метаданных аддона в Home Assistant.
- Функциональность версии 0.2.0 с выбором устройств сохранена без изменений.

## 0.2.0 — 8 сентября 2026

### Выбор устройств
- Добавлен встроенный веб-интерфейс выбора устройств Яндекс Умного дома.
- Аддон получает полный список доступных устройств через официальный API Яндекса, но сохраняет только выбранные пользователем `device_id`.
- Не выбранные устройства не обрабатываются циклом моста.
- Выбор сохраняется в `/data/selected_devices.json` и переживает перезапуск/обновление аддона.
- Добавлена интеграция веб-интерфейса через Home Assistant Ingress.
- В интерфейсе отображаются имя, модель, тип и `device_id` каждого устройства.
- Добавлена иконка и пункт панели Home Assistant для быстрого открытия интерфейса.

### Безопасность
- В интерфейс не выводится OAuth-токен.
- При сохранении принимаются только `device_id`, реально возвращённые API Яндекса.

### Ограничения
- Эта версия всё ещё работает в режиме только чтения.
- Выбор устройств является подготовкой к публикации выбранных устройств как сущностей Home Assistant.
- Управление устройствами и создание сущностей Home Assistant будут добавлены следующими версиями.

## 0.1.1 — 8 сентября 2026

### Исправления
- Исправлена авторизация запросов к официальному API Яндекс Умного дома: используется стандартный `Bearer` OAuth-заголовок.
- Улучшена обработка ошибок авторизации и сетевых ошибок.
- Добавлены более понятные сообщения в логах аддона.

### Интерфейс и документация
- Описание аддона переведено на русский язык.
- Документация и настройки дополнены русскими пояснениями.
- Добавлена русская локализация полей конфигурации.

### Функциональность
- Сохранён режим только чтения.
- Автоматически ищется устройство модели `YNDX-00019`, если `device_id` не указан вручную.
- Получается текущее состояние найденного устройства.
- Управление устройством в этой версии намеренно не выполняется.

## 0.1.0 — 8 сентября 2026

### Первый релиз
- Создан аддон-мост между Яндекс Умным домом и Home Assistant.
- Добавлена настройка OAuth-токена Яндекса.
- Добавлено чтение устройств через официальный API Яндекс Умного дома.
- Добавлен поиск устройства `YNDX-00019`.
- Добавлено периодическое получение состояния устройства.
- Поддерживаются архитектуры `amd64` и `aarch64`.
- Управление устройствами в этой версии отключено.

## План развития

- **0.2.x** — выбор устройств для публикации в Home Assistant.
- **0.3.0** — создание сущностей `light` в Home Assistant через MQTT Discovery только для выбранных устройств.
- **0.4.0** — управление устройствами: включение, выключение, яркость, RGB и цветовая температура.
- **0.5.0** — полноценная синхронизация состояния между Яндексом и Home Assistant.
- **0.6.0+** — несколько типов устройств, расширенные возможности и автоматическое восстановление после временной потери соединения.

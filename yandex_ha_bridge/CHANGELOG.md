# История изменений

## 0.3.1 — 8 сентября 2026

### Home Assistant Integration
- Интеграция переименована в **Yandex HA Bridge**.
- Используется уникальный домен `yandex_ha_bridge`.
- Убрана конфликтующая идентичность `yandex_smart_home`.
- Интеграция может работать одновременно со сторонней **Yandex Smart Home**.
- Config Flow: OAuth-токен → получение устройств → выбор устройств → создание Config Entry.
- Options Flow позволяет изменить список выбранных устройств.
- Выбранные устройства регистрируются через Device Registry Home Assistant.

### Свет
- Добавлена сущность `light` для совместимых устройств.
- Включение и выключение.
- Яркость.
- RGB/HSV.
- Цветовая температура.
- Преобразование яркости между шкалами Home Assistant 0–255 и Яндекс 0–100.

### HACS и документация
- Обновлено имя интеграции в `hacs.json`.
- Обновлены README и описания.
- Версия аддона и build pipeline синхронизированы с 0.3.1.

## 0.3.0 — 8 сентября 2026

### Home Assistant Integration
- Добавлена отдельная стандартная custom integration.
- Добавлен Config Flow: токен → получение устройств → выбор устройств.
- Выбранные устройства сохраняются в Config Entry Home Assistant.
- Добавлен Options Flow для изменения списка выбранных устройств.

### Свет
- Добавлена сущность `light` для совместимых устройств.
- Поддержаны включение и выключение через `devices.capabilities.on_off`.
- Поддержана яркость через `devices.capabilities.range` / `brightness`.
- Поддержан RGB/HSV через `devices.capabilities.color_setting`.
- Поддержана цветовая температура через `temperature_k`.

### Архитектура
- Основной способ добавления устройств перенесён в **Настройки → Устройства и службы**.
- Боковая панель Yandex HA Bridge сохранена для диагностики и технического обслуживания App.
- Добавлены HACS-метаданные для установки custom integration.

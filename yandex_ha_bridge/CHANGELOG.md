# История изменений

## 0.3.0 — 8 сентября 2026

### Home Assistant Integration
- Добавлена отдельная стандартная custom integration `Yandex Smart Home`.
- Добавлен Config Flow: токен → получение устройств → выбор устройств.
- Выбранные устройства сохраняются в Config Entry Home Assistant.
- Добавлен Options Flow для изменения списка выбранных устройств.
- Создание сущностей выполняется только для выбранных устройств.

### Свет
- Добавлена сущность `light` для совместимых устройств.
- Поддержаны включение и выключение через `devices.capabilities.on_off`.
- Поддержана яркость через `devices.capabilities.range` / `brightness`.
- Поддержан RGB/HSV через `devices.capabilities.color_setting`.
- Поддержана цветовая температура через `temperature_k`.
- Добавлено преобразование яркости между шкалами Home Assistant 0–255 и Яндекс 0–100.
- Добавлено создание Device Registry с идентификатором устройства Яндекса.

### Архитектура
- Основной способ добавления устройств перенесён в стандартный интерфейс **Настройки → Устройства и службы**.
- Боковая панель Yandex HA Bridge сохранена для диагностики и технического обслуживания App.
- Добавлены HACS-метаданные для установки custom integration.

### Документация
- Полностью переписана инструкция установки и настройки.
- Описано различие между App и Integration.
- Описаны OAuth scopes `iot:view` и `iot:control`.
- Описано управление светом, яркостью, RGB и цветовой температурой.

## 0.2.1 — 8 сентября 2026

### Исправления
- Обновлена версия релиза для корректного обнаружения обновления в Home Assistant.
- Исправлена YAML-строка `description`: двоеточие в русском описании теперь корректно заключено в кавычки.
- Функциональность версии 0.2.0 с выбором устройств сохранена.

## 0.2.0 — 8 сентября 2026

### Выбор устройств
- Добавлен встроенный веб-интерфейс выбора устройств Яндекс Умного дома.
- Аддон получает полный список доступных устройств через официальный API Яндекса, но сохраняет только выбранные пользователем `device_id`.
- Не выбранные устройства не обрабатываются циклом моста.
- Выбор сохраняется в `/data/selected_devices.json` и переживает перезапуск/обновление аддона.
- Добавлена интеграция веб-интерфейса через Home Assistant Ingress.
- В интерфейсе отображаются имя, модель, тип и `device_id` каждого устройства.
- Добавлена иконка и пункт панели Home Assistant для быстрого открытия интерфейса.

### Безопасность
- В интерфейс не выводится OAuth-токен.
- При сохранении принимаются только `device_id`, реально возвращённые API Яндекса.

### Ограничения
- Эта версия работала в режиме только чтения.
- Выбор устройств являлся подготовкой к публикации выбранных устройств как сущностей Home Assistant.
- Управление устройствами и создание сущностей Home Assistant добавлены в 0.3.0.

## 0.1.1 — 8 сентября 2026

### Исправления
- Исправлена авторизация запросов к официальному API Яндекс Умного дома: используется стандартный `Bearer` OAuth-заголовок.
- Улучшена обработка ошибок авторизации и сетевых ошибок.
- Добавлены более понятные сообщения в логах аддона.

### Интерфейс и документация
- Описание аддона переведено на русский язык.
- Документация и настройки дополнены русскими пояснениями.
- Добавлена русская локализация полей конфигурации.

### Функциональность
- Сохранён режим только чтения.
- Автоматически ищется устройство модели `YNDX-00019`, если `device_id` не указан вручную.
- Получается текущее состояние найденного устройства.
- Управление устройством в этой версии намеренно не выполняется.

## 0.1.0 — 8 сентября 2026

### Первый релиз
- Создан аддон-мост между Яндекс Умным домом и Home Assistant.
- Добавлена настройка OAuth-токена Яндекса.
- Добавлено чтение устройств через официальный API Яндекс Умного дома.
- Добавлен поиск устройства `YNDX-00019`.
- Добавлено периодическое получение состояния устройства.
- Поддерживаются архитектуры `amd64` и `aarch64`.
- Управление устройствами в этой версии отключено.

## План развития

- **0.4.x** — расширенное управление устройствами и дополнительные capabilities.
- **0.5.x** — полноценная двусторонняя синхронизация состояния.
- **0.6.x+** — несколько типов устройств, расширенные возможности и автоматическое восстановление после временной потери соединения.
